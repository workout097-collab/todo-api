# TODO API

Backend API for task management built with FastAPI.

## Features

- User registration
- JWT authentication
- Protected routes
- Create tasks
- Get tasks
- Delete tasks
- SQLite database
- SQLAlchemy ORM

## Tech Stack

- FastAPI
- Python
- SQLAlchemy
- SQLite
- JWT Authentication
- Uvicorn
