# VTaskForge API

Production-ready backend API for task management built with FastAPI, PostgreSQL and JWT authentication.

## Features

- User registration
- JWT authentication
- Protected routes
- Create tasks
- Get tasks
- Delete tasks
- PostgreSQL database
- SQLAlchemy ORM

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT
- Pydantic
- Uvicorn

## Run locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
